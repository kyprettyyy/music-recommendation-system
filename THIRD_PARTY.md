# Provenance and third-party material

The supplied folder was named `MusicRecommend-master`. Its original README describes an undergraduate graduation project, names the Bilibili profile https://space.bilibili.com/383843542 and a historical demonstration at fishei.cn. The original README is retained verbatim as `README.original.md`. The exact upstream repository and license were not supplied or verified. This repository must not be represented as wholly original authorship.

The original README credits the web player to https://github.com/Ezenlee/WebMusicPlayer and audio-processing learning material to https://www.youtube.com/watch?v=gp2wZqDoJ1Y . Third-party asset notices are retained. No blanket license is granted to third-party code, images, fonts or data by this cleanup.

GTZAN recordings, database contents and pretrained weights are excluded from version control. Supplied diagrams and UI screenshots illustrate the historical project, rather than a fresh verification of a running application.
