# 音乐推荐系统

Django 音乐播放器 + PyTorch AlexNet 风格分类器 + 基于音频内容的 Top-5 推荐。整理自所提供的历史项目文件夹，原始说明和第三方来源见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 已找到的功能

- 音频重采样至 22050 Hz、合并单声道、裁剪或补齐到 5 秒。
- 使用 torchaudio 提取 128 维 MFCC，送入 AlexNet 风格网络识别 10 类音乐风格。
- 从随机抽取的 20 首候选歌曲中，按偏好风格的模型原始分数排序，返回前 5 首。
- Django 页面支持播放器、随机列表和随机同风格列表。

未在文件夹中发现协同过滤、歌词 Word2Vec 或多模态融合的可验证实现。简历中相关表述不能仅由本仓库证明；团队人数、个人贡献和实习身份也需要独立材料支持。

## 运行

详细命令见 [英文 README](README.md)。需要 Python 3.10、requirements.txt 中的依赖、GTZAN 音频及兼容模型权重。数据集、数据库和模型权重未纳入 Git。启动后访问 http://127.0.0.1:8000/project 。

训练 Notebook 为历史实验资料，引用了未随文件夹提供的独立测试标签文件，需要调整路径和运行设备；不能直接视为一键复现脚本。未重训模型，未验证准确率和端到端音频推荐。
