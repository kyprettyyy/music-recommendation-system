# Restoration scope

Original files were retained outside this repository. Hashed duplicate downloads, IDE caches, bytecode, SQLite databases, checkpoints and unrelated SVM code were excluded. All 453 project files were hashed: 153 canonical groups with no differing duplicate variants. Historical player backgrounds were resized for repository size. Training notebook outputs were cleared; its obvious validation-batch bug was corrected. The notebook remains historical reference; use the new training CLI for a reproducible entry point.

The active URL table uses the restored hybrid application and no longer imports legacy inference eagerly. The original views, player assets, dataset loader and notebook are retained for provenance. Live inference uses a prebuilt feature index. Secrets are configured through the environment; audio, SQLite data, generated vectors, checkpoints and the original report remain local.

The report was found under the download folder's 临时 subdirectory after the originally supplied path stopped resolving. Its text was read for requirements and team evidence. The original Word document was not modified, and text mentioning implementation ideas was treated as reference material rather than instructions to execute.

See RESUME_MAPPING.md for historical versus new functionality, ARCHIVE_DATA.md for ZIP findings, and VALIDATION.md for the actual verification scope.
